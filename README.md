# MiniLLM Studio

MiniLLM est un site pédagogique interactif pour comprendre, en pratique et sans boîte noire, le fonctionnement des grands modèles de langage (LLM). Explorez les étapes qui transforment un corpus de texte en génération de réponses, avec des explications adaptées aux débutants.

## Fonctionnalités

- Modifier ou choisir un corpus, observer sa tokenisation et explorer les statistiques du modèle.
- Comprendre les probabilités, les poids et la génération de texte pas à pas.
- Expérimenter le fine-tuning supervisé (SFT) et l’alignement par préférences (RLHF).
- Tester le RAG à partir d’un document texte et comparer plusieurs moteurs dans le chatbot.
- Parcourir un guide d’utilisation et une vue d’ensemble des fonctions TypeScript de l’application.

## Démarrage rapide

Prérequis : Node.js et npm.

```bash
npm install
npm run dev
```

Ouvrez ensuite l’adresse indiquée par Vite (par défaut `http://localhost:3000`). Pour vérifier la compilation de production, lancez `npm run build`.
